How to use

  • Filter manually to start — set criteria and apply to produce page 1.
  • Stack further operations on top: each narrows or analyzes the previous page's case set.
  • Back pops the stack; click a breadcrumb to view any past page read-only.

About the data

  • Federal district courts and appellate circuits.
  • Cases filed since January 20, 2025.
  • Full docket entries; OCR text of attached documents where available.
  • Full-text search runs on docket-entry descriptions (indexed), not document contents.
